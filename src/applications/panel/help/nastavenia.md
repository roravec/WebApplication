# Nastavenia

Všetko, čo sa nastaví raz a potom mení len občas — na jednom mieste, v záložkách. Vidíte len záložky, na ktoré máte
právo.

| Záložka | Čo tam je | Návod |
|---|---|---|
| **Firmy** | údaje firmy, DPH, bankové účty a Fio token, logo a pečiatka, e-shopy firmy, export do Omegy, účtovníčka, e-mail s faktúrou, číselné rady | [Firmy](help:nastavenia-firmy) |
| **E-shopy** | pripojenie e-shopov (kľúč Webservice), **stavy objednávok** | [E-shopy](help:nastavenia-eshopy) |
| **Náklady objednávok** | koľko vás stojí doprava, platba a balné (pre maržu) | [Náklady objednávok](help:naklady-objednavok) |
| **Legislatíva** | sadzby DPH, texty na dokladoch, hranica pre DPH | [Legislatíva](help:legislativa) |
| **Projekty** | formát čísla úlohy v commitoch, git repozitáre (GitHub, GitLab, vlastný server) | [Commity pri úlohách](help:commity) |
| **Systém** | plánovač úloh (cron), integrácie (Nextcloud …), prehľad API kľúčov | [Systém](help:nastavenia-system) |
| **Zamestnanci a roly** | účty, roly, práva, firmy a e-shopy každého človeka, prehľad „kto čo smie“ | [Zamestnanci a roly](help:zamestnanci), [Roly a práva](help:roly-a-prava) |
