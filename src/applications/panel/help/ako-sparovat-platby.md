# Ako spárovať platby z banky

Raz za čas (ideálne týždenne):

1. **Faktúry → Úhrady (výpis, Fio)**.
2. **Fio**: vyberte účet a obdobie → **Stiahnuť pohyby**. Iná banka: stiahnite výpis **CAMT.053 (XML)** a nahrajte
   ho → **Načítať výpis**.
3. Skontrolujte navrhnuté párovanie (prijaté platby → faktúry podľa VS, odchádzajúce → náklady).
4. **Zapísať zaškrtnuté**.

Faktúry sa označia ako uhradené, náklady tiež. Podrobne: [Úhrady](help:uhrady).
