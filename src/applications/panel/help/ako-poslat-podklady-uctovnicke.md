# Ako poslať podklady účtovníčke

## Automaticky (odporúčané)

**Nastavenia → Firmy → firma → Pre účtovníka (mesačný balík)**: e-mail účtovníčky, zaškrtnúť **Posielať
automaticky za predchádzajúci mesiac** a deň → **Uložiť firmu**. Potom každý mesiac odíde balík sám.

## Ručne

1. **Faktúry → Pre účtovníka**.
2. Vyberte firmu a mesiac → **Zobraziť**.
3. **Poslať účtovníkovi** (alebo **Stiahnuť ZIP** a pošlite inak).

Pred koncom mesiaca: zadajte všetky prijaté doklady do **Nákladov** (aj so súborom) a spárujte platby z banky.
Návod pre účtovníčku k importu: [Export do Omegy](help:export-omega).
