# Môj účet

Otvoríte kliknutím na svoje meno dole vľavo.

## Zmena hesla

1. **Súčasné heslo**.
2. **Nové heslo** (aspoň toľko znakov, koľko panel píše) a **Nové heslo znova**.
3. **Zmeniť heslo**.

> Heslo nikomu nehovorte a nepoužívajte ho inde. Ak ho zabudnete, nové vám nastaví správca.

## Upozornenia e-mailom

Vyberte, či chcete e-mail o upozorneniach **hneď**, **raz denne** (ráno súhrn) alebo **vôbec** (len zvonček 🔔 v paneli).
Podrobne: [Upozornenia](help:upozornenia).

## API kľúče

Ak máte právo *API — vlastné API kľúče*, vytvoríte tu kľúč pre program (testovací prípravok, CI, skript) a zrušíte
ho. Podrobne: [API kľúče](help:api-kluce).
